- Target: original English-language learning content with Vietnamese UI support, mapped to the public SRTC certificate “Những vấn đề cơ bản về chứng khoán và thị trường chứng khoán”.

- No affiliation, no copied official text, no certificate, and no pass guarantee.
- The app target is 70%; it is a practice threshold, not an official pass mark.

## 2. Public SRTC reference facts

- 8 topics.
- 12 sessions: 11 study sessions plus a final test.
- Reference fee: 3.2 million VND.
- Fees, schedules, teaching format, and assessment rules can change; verify current details with SRTC.
- The electronic CCHN rules under Thông tư 135/2025/TT-BTC effective from 01/07/2026 should be checked against official sources.
- Recorded metadata: `source = "SRTC public basic securities program outline"`, `verifiedOn = "2026-11-12"`, `volatile = true`. All study facts carry this metadata because fee, schedule, and assessment details can change.

## 4. App architecture

- 2 orientation lessons in `sec-mod-0`.
- 8 generated topic modules × 2 lessons = 16 core lessons.
- 2 final-review lessons in `sec-mod-9`.
- 3 practice mocks, each with 40 questions and 60 minutes; target 70%.
- Optional 2-lesson trading-app bridge in `sec-mod-10`.
- Total core/review study: 20 lessons, plus 2 optional bridge lessons.

Lessons follow the existing NeZha shape: objectives, original `contentHtml`, key terms, flashcards, a mixed MCQ/true-false quiz, and a Feynman prompt.

## 5. Files

- `securities-content.js`: eight topics, ten facts per topic, one 60-minute mock section, unofficial disclaimer.
- `exams-securities.js`: builds and registers three 40-question practice mocks with four options per question.

Runtime registration, PWA cache entries, `package.json` scripts, the BA stats path, and `AGENTS.md` were also updated. Preserve the existing exam engine and local-first behavior.
